# Petunjuk Tahap 02 — Admin Cabang

Paket ini **melanjutkan** Tahap 01 Admin dan Kasir pada repository yang sama.

1. Pastikan `admin-brief/` dari paket Tahap 01 tersedia di root proyek.
2. Ekstrak ZIP tahap 02 di root proyek sehingga prompt berada di `admin-stage-02/PROMPT_OPENCODE_ADMIN_TAHAP_02.md`.
3. Jalankan `opencode` dari root proyek.
4. Kirim: `Baca admin-stage-02/PROMPT_OPENCODE_ADMIN_TAHAP_02.md dan kerjakan seluruh Tahap 02. Jangan redesign Tahap 01 atau mengubah modul Kasir yang telah berfungsi. Jalankan screenshot QA.`
5. Review screenshot hasil, terutama Penerimaan, Pengajuan dan Detail PO, sebelum mengunci visual.

Batas: prototype frontend tidak sama dengan autentikasi, otorisasi dan transaksi server production. Temuan kebutuhan yang belum diputuskan PRD wajib ditandai sebagai pending, bukan disamarkan.
