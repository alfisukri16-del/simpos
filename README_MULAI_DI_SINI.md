# PAKET REFERENSI OPENCODE — SIMPOS OPTIK MEKAR JAYA (KASIR)

Urutan penggunaan:
1. Ekstrak seluruh isi ZIP.
2. Letakkan folder paket ini di root workspace proyek yang akan dikerjakan OpenCode; folder `references/` dan `assets/` harus tetap terjaga.
3. Berikan isi `MASTER_PROMPT_OPENCODE.txt` kepada OpenCode. Pastikan OpenCode mempunyai akses baca ke semua file.
4. Untuk desain, dua referensi PALING penting adalah `references/01-login-FINAL.png` dan `references/02-dashboard-FINAL.png`.
5. Gambar 03-09 adalah acuan untuk layar lain dengan tingkat kepastian lebih rendah; tetap baca PRD bila screenshot kurang akurat.
6. Foto crop di `assets/` hanya boleh digunakan sebagai unsur dekoratif, bukan sebagai pengganti HTML interaktif.

Tidak ada source code frontend dalam paket ini. Untuk mengecek/menyalin logika versi lama, sediakan ZIP project sebelumnya secara TERPISAH dan jadikan hanya sebagai referensi fungsional, bukan desain final.
