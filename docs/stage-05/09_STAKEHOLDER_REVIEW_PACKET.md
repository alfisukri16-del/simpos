# 09 — Paket Review Stakeholder (nonteknis)

Bapak/Ibu Pemilik Optik Mekar Jaya, tim proyek mengusulkan 14 pilihan sementara
(daftar di `08_*`; rekomendasi analis ★ di `02_*`). **Belum ada yang berlaku** —
sistem berjalan dengan pengaman lama sampai Bapak/Ibu mengesahkan.

## Yang perlu Bapak/Ibu jawab (15 menit)

Untuk tiap nomor 1–14 di kuesioner: lingkari A/B/C + tulis catatan bila perlu.
Fokus utama: (1) siapa menandai PO Selesai; (2) kapan stok pusat berkurang;
(3) perlu/tidaknya tahap pengiriman; (10) setujui contoh file laporan yang kami tunjukkan.

## Cara mengesahkan

1. Isi `02_STAKEHOLDER_QUESTIONNAIRE.md` (tulis tangan/ketik).
2. Tulis keputusan final per item di `04_APPROVAL_SHEET.md` + nama, jabatan, tanggal, tanda tangan.
3. Cantumkan versi policy (mis. `POL-2026-10-12-v1`) dan referensi notulen/rapat bila ada.
4. Kembalikan kedua file — tim membuka gerbang implementasi per batch (`05_*`).

## Pertanyaan lanjutan yang masih kami butuhkan

- Bukti serah terima PO seperti apa yang sah (nota fisik/TTD/foto)?
- Siapa di toko yang boleh mencatat pengiriman pusat→cabang?
- Batas toleransi selisih yang masih wajar tanpa review (0? 1 unit? nilai Rp)?
- Contoh file PDF/Excel laporan: setujui / minta ubah apa?
- Siapa petugas provisioning akun produksi dan atasan pemberi otorisasi?

Tanpa jawaban tertulis, status tetap PENDING dan gerbang implementasi tetap CLOSED.
